# 执药备考工具 MVP

一个面向执业西药师与执业中药师考生的离线桌面考试应用。

## 当前已经完成

- 现代化学习驾驶舱：首页倒计时、掌握度、今日学习路径与科目进度。
- 西药 / 中药学习方向切换。
- 已建立 SQLite 主题库，并导出 3,580 道可在网页中作答的题目（其中 7 道为原创演示题）。
- 每次按西药 / 中药方向随机抽取 20 题，包含单选、多选、计时、收藏与题号卡。
- 自动成绩报告、逐题解析、薄弱知识点建议。
- 错题自动归集与最近一次成绩本地保存。
- 会员权益和测试价格页面，未连接真实支付。
- 桌面端与手机端响应式布局。
- Electron 桌面程序外壳，可打包成 Apple 芯片 Mac 的 `.app`、`.dmg` 和 `.zip`。
- 自定义科目和 10 / 20 / 50 / 100 题随机组卷。
- 专项练习即时解析与模拟考试统一交卷两种模式。

## 本地预览

```bash
pnpm install
pnpm dev
```

浏览器访问 `http://127.0.0.1:5173/`。

## 桌面程序

```bash
pnpm desktop:preview
pnpm desktop:dist
```

桌面安装包生成到 `release/`。详细安装与销售说明见 `桌面版使用说明.md`。

## 题库文件

- 主数据库：`data/yaoshi_question_bank.sqlite`
- 网页运行数据：`public/data/question-bank.json`
- 导入报告：`data/import-report.json`
- 重复导入脚本：`scripts/import_question_bank.py`

本次共登记 306 个原始及压缩包内文件，识别 190 份资料，去除 93 个重复文件和 1,053 条重复试题记录。另有 9 份纯扫描 PDF 已登记为 `needs_ocr`，尚未转成可作答题目。

## 资料与版权边界

第三方资料及自动导入题目统一标记为 `review_required`，仅表示已完成技术导入，不表示已经获得复制、改编或商业销售授权。商业发布前应逐项确认来源、授权和内容准确性；7 道项目原创演示题标记为 `original`。
