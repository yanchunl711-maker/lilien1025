# User Preferences

Last updated: 2026-07-18

## Communication

- User prefers Chinese for setup, workflow, and operational guidance.
- User often wants Codex to act directly rather than only explain.
- Use concise, practical status updates while working.
- For non-technical tasks, avoid unnecessary technical detail unless it helps the user make a decision.

## Working Style

- Prefer end-to-end completion: install, configure, verify, and sync when possible.
- When external login, password, captcha, 2FA, payment, or sensitive credentials are required, pause and let the user complete that step.
- For repositories containing personal records, receipts, or private project material, default to private GitHub repositories.

## Safety Preferences

- Do not expose private keys, passwords, tokens, OTPs, or payment details.
- Public keys can be shared when needed for SSH setup.
- Ask before destructive actions such as deleting files, force pushes, resets, or changing access permissions.
